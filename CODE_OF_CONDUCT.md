# Code of Conduct

We want this project to be welcoming and useful to everyone.

Expected behavior includes respectful communication, constructive reviews, clear technical feedback, and consideration for different backgrounds and experience levels.

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, sexualized comments, doxxing, and publishing private information without consent.

Report concerns privately to the maintainer through the contact route in [SECURITY.md](SECURITY.md). The maintainer will review reports and may remove comments, close contributions, or restrict participation when necessary.
